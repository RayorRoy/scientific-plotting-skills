# Sources and relationship to other skills

The basic appearance records the user's Times selection, large typography, panel-ID placement, title omission, colorbar preferences and accepted figure previews. It is a personal convention, not a JSV/JASA/PRL publisher specification.

The PRL-inspired profile adapts three user-provided screenshots. The original articles/DOIs and original physical figure sizes were not supplied. Screenshot hashes and observations remain in the profile; the images themselves stay in the local research record and are not distributed. Source font/point-size/color estimates are distinct from user confirmation of the resulting adaptation.

General scientific-visualization principles were informed by K-Dense's [Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills), specifically scientific-visualization. This skill's Python helpers were written for the personal workflow and do not import that skill. It is optional guidance for specialist questions; the personal skill supplies the selected appearance and execution conventions. Do not combine competing default styles.

Preserve upstream notices if third-party code/assets are incorporated later. No manuscript PDFs, raw research datasets, original reference screenshots or proprietary system fonts are distributed here. Publisher requirements must be checked against current official guidance for an actual target venue.
